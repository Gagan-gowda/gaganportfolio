Expandable Navigation Cards

A custom SharePoint Framework web part designed to improve navigation and content discoverability through expandable card-based navigation.

Project screenshots

01

PROJECT OVERVIEW

A cleaner way to navigate SharePoint.

The Expandable Navigation Cards solution is a custom SharePoint Framework (SPFx) web part designed to provide an organized and user-friendly navigation experience within SharePoint Online.

The web part allows related resources to be grouped into visually distinct cards. Users can expand a card when they need additional links, keeping the page clean while making important resources easier to discover.

THE GOAL Make important SharePoint resources easier to discover without cluttering the page.
02

THE PROBLEM

Too many links. Too much clutter.

01

Cluttered navigation

Large portals can contain many resources spread across different pages, libraries and business areas.

02

Difficult discovery

Users can struggle to locate important documents, forms and frequently used resources.

03

Poor organization

Traditional link lists do not always clearly separate different business functions.

04

Time wasted searching

Employees can spend unnecessary time searching for resources that should be easier to access.

03

THE SOLUTION

Organize. Expand. Navigate.

The solution presents navigation in a clear card-based layout. Each card represents a business area and expands to reveal related links and resources only when required.

01 Categorize

Group related resources into meaningful business categories.

02 Expand

Reveal additional navigation only when the user needs it.

03 Navigate

Give users quick access to the resource they need.

04

KEY FEATURES

Designed around the user experience.

01

Responsive design

Card-based navigation adapts to different screen sizes and SharePoint page layouts.

02

Expandable sections

Users can control how much navigation information is displayed at a time.

03

Multiple categories

Supports business-focused categories such as policies, forms, resources and services.

04

Configurable navigation

Navigation items can be configured according to the requirements of each SharePoint site.

05

TECHNOLOGY

Built for modern SharePoint.

01

PROJECT OVERVIEW

A flexible expandable menu for SharePoint.

The Expandable Menu is a custom SharePoint Framework (SPFx) web part developed to provide a simple and flexible expandable navigation experience within modern SharePoint pages.

The component allows content authors to create a menu heading and associate multiple related links underneath it. Users can expand the menu when they need access to those resources and collapse it when they are finished.

THE GOAL Provide a simple, configurable navigation component that keeps SharePoint pages organized and easy to use.
02

THE PROBLEM

Navigation should not overwhelm the page.

01

Limited navigation flexibility

Standard SharePoint components may not provide the exact expandable navigation experience required by a page.

02

Too many visible links

Displaying every related resource at once can make a page difficult to scan.

03

Inconsistent page layouts

Navigation components need to work across different SharePoint page sections and layouts.

04

Authoring complexity

Site owners need a simple way to configure navigation without modifying source code.

03

THE SOLUTION

A configurable navigation experience.

The Expandable Menu provides content authors with a configurable navigation component that can be placed directly within modern SharePoint page layouts.

01 Configure

Define the menu heading, typography and navigation links through the web part configuration.

02 Expand

Users can expand the menu to reveal available navigation links.

03 Navigate

Users can select the required resource and continue directly to the destination.

04

KEY FEATURES

Flexible configuration for page authors.

01

Expand & collapse

Users can reveal or hide navigation links with a simple interaction.

02

Custom headings

Content authors can define meaningful headings for different navigation areas.

03

Typography controls

Supports configurable heading sizes and text formatting options.

04

Multiple links

Supports multiple related navigation links within a single expandable menu.

05

CONFIGURATION

Built for flexible SharePoint page design.

01

Menu heading

Configure a custom heading based on the purpose of the navigation section.

02

Heading size

Choose from predefined sizes or configure a custom heading size.

03

Text formatting

Apply bold, italic and underline formatting to the menu heading.

04

Responsive placement

Designed to work within different modern SharePoint page layouts and sections.
